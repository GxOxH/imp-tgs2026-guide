## アクセス制限のしくみ

`index.html` は**ページ全体を AES-256-GCM で暗号化**してあります。
サーバーには暗号文しか置かれておらず、ソースを表示しても内容は読めません。

- 鍵導出：PBKDF2-SHA256、300,000回、16バイトのランダムsalt
- 鍵素材：`ID + 改行 + パスワード`（IDは大文字に正規化、パスワードは大小を区別）
- 復号：ブラウザの Web Crypto API。**入力値はどこにも送信されません**
- 同じタブ内では sessionStorage に保持し、再入力を省略します

### 強度について

これは「URLを知っている人が中身を見られないようにする」ための仕組みです。
暗号文は誰でもダウンロードできるので、**パスワードが短いとオフラインで総当たりされ得ます。**
身内向け・イベント期間限定の用途としては十分ですが、機密情報を置く用途には向きません。

本気のアクセス制御が必要になった場合は Cloudflare Pages + Cloudflare Access
（無料枠でメール認証、50人まで）が選択肢になります。ただし iframe 埋め込みとは両立しません。

## 更新のしかた

平文の `TGS2026_guide.html` を更新してから、暗号化してコミットします。

```bash
# 1. 平文を更新（ビルド成果物）
# 2. 暗号化して index.html を作り直す
node encrypt.js IMP SHIKONE

# 3. コミット＆プッシュ
git add -A
git commit -m "更新内容"
git push
```

反映まで1〜2分。ブラウザに古い版が残る場合は `Ctrl+F5`。

> `TGS2026_guide.html`（平文）と公式WEBマップPDFは `.gitignore` で除外しています。
> **公開リポジトリなので、平文をコミットすると暗号化の意味がなくなります。**

## Googleサイトへの埋め込み

「挿入 → 埋め込む → 埋め込みコード」に1行貼るだけです。

```html
<iframe src="https://gxoxh.github.io/imp-tgs2026-guide/"
        style="width:100%;height:1500px;border:0" loading="lazy"
        title="IMP TGS2026 ガイド"></iframe>
```

- パスワード入力は iframe の中で完結します。閲覧者は埋め込み枠内でIDとパスワードを入れます。
- 高さは固定なので 1200〜1600px で調整してください。
- iframe はサードパーティ扱いになるため、ブラウザ設定によっては sessionStorage が使えず、
  ページを開き直すたびに再入力になることがあります（エラーにはなりません）。

## 技術メモ

- 単一HTMLで完結。データ（ブース1,281／タイトル568／リンク456／デバイス188／ステージ62／ノベルティ285／フード21）はすべてインライン
- 外部から読むのは Google Fonts と Three.js（cdnjs）のみ。どちらも落ちてもページは壊れません（3Dマップは平面図にフォールバック）
- 3D会場マップは three.js。1ホール＝112.5m×60mの実寸でモデル化
- 画像は IMP ロゴのみ（Base64埋め込み）。**出展社のロゴ・写真は使用していません。**
  一覧の図版は小間番号から描くミニ会場図と、タイトル名のハッシュから生成する図案です
- 配色は `DESIGN.md`（Electric Neo-Chiba）に準拠。ダーク／ライト切替対応
- フォント：英数字 Inter ／ 日本語 Noto Sans JP
